# Vellum для Android

Нативный клиент на Kotlin и Jetpack Compose для OpenAI-совместимых API.
Ключ хранится на устройстве и уходит напрямую провайдеру — без веб-прокси.

В приложении: несколько провайдеров и пресеты (OpenAI, OpenRouter, Groq, DeepSeek, Mistral, Together, Fireworks, xAI, Ollama, LM Studio), поток ответа, стоп, варианты и правка сообщения, вложения, системная инструкция и память, температура и штрафы, библиотека промптов, архив и инкогнито, темы «чернила» и «иней», импорт и экспорт того же JSON, что и у веб-версии.

## APK через GitHub

1. Залейте репозиторий на GitHub.
2. Откройте вкладку Actions.
3. Выберите **Build APK** и нажмите **Run workflow**.
4. Скачайте артефакт `vellum-debug` и установите APK.

Сборка описана в `.github/workflows/android-apk.yml` (JDK 17, Android SDK 35, Gradle 8.11.1, debug-подпись). Локально из каталога `android`: `./gradlew assembleDebug`.

Для Ollama на эмуляторе укажите `http://10.0.2.2:11434/v1`. На телефоне — IP компьютера в локальной сети. HTTP разрешён, чтобы достучаться до локальных серверов.
